## 4.1【P0】ランディングとして「次のアクション」が示されていない

### 現状の概要ページ
- **数値カード 4 枚**: セッション数 140 / Q&Aペア 6308 / 発言者 502 / 約束事項 502
- **ナビカード 3 枚**: トピック分析 / 約束トラッカー / 発言者分析
- **月別セッション数バー**
- **52 週カレンダー**
- **最近のセッション 5 件テーブル**
- **注目トピック 10 個**
- 最終更新タイムスタンプ

### 問題

1. **数値の意味が分からない**: 6308 Q&A はどう解釈すれば良いか、新規ユーザーには手がかりがない。「先週比 +120 件」のような変化量が出ていない。
2. **ナビカード 3 枚は上タブと完全重複**: 上のタブ（概要／トピック分析／約束トラッカー／発言者分析）と、ボディ内のカード 3 枚が同じリンク先。タブとカードのどちらでも遷移可能だが、ユーザーは混乱する。
3. **月別バーチャート**: 過去 3 ヶ月分しか積まれておらず、トレンドと言うには情報量が不足。クリックしても何も起きない（ドリルダウン無し）。
4. **カレンダー**: 過去 1 年表示だが、データは 3 ヶ月分しかなく、ほとんどグレー。
5. **最近のセッション 5 件**: ホームと役割が完全に被っている。
6. **注目トピック**: クリックすると `/browse?topic=...` に飛ぶが [02 章](02-cross-cutting-issues.md) の通り 0 件になる。

要するに「眺めるだけで離脱する」ダッシュボードになっている。**何かを発見させる仕掛けが無い**。

### 改善案: 「気付きを与える」ダッシュボードへ

ダッシュボードの存在意義は、フィルタや検索では見えない**鳥瞰**を提供することにある。次の 4 ブロックに再構成する:

1. **今週のハイライト**（自動キュレーション）
   - 「今週最も発言した議員 上位 5 名」
   - 「今週最多のトピック 上位 3 件」
   - 「新たに記録された約束事項 上位 5 件」
   - 各カードはクリックで該当セッション or 議員ページへ
2. **異常値・要注目**
   - 「回避度高 + サンプル十分」な答弁ペア（[05 章](05-evasion-score.md) の改良版指標で）
   - 「同じ議員が複数委員会で同じ質問」を検出
   - 「閣僚が約束したが、まだ次回質疑が無い」
3. **会期全体の統計**
   - 月別バーは年単位の比較に切り替え、過去会期と並べる
   - カレンダーは半年に縮め、密度を上げる
4. **テーマ別エントリーポイント**
   - 「防災・災害」「外交・安全保障」「経済・財政」など固定分類で章入口

### コンパクト版（短期で出来ること）
- 数値カードに「先週比」「過去 30 日内訳」を併記
- ナビカード 3 枚を削除（タブで足りる）
- 月別バーを「今会期累計」「直近 4 週」の 2 系列に変更

## 4.2【P0】トピック分析: ヒートマップが疎すぎて「見るに値しない」

### 現状
- 20 トピック × 23 委員会 = 460 セル中、**非ゼロは 23 セル（5%）**
- 委員会名のヘッダ（縦書き）がスクリーンショット上では切れている／読みにくい
- 「不明」委員会が混入

### 原因
- LLM が**セッション単位で生成する広域トピック名**は session 間で揺れる（同じテーマでも毎回ちょっと違う名前が付く）→ 集計時に bin が増えすぎる
- 上位 20 を取るので、頻度 1〜2 のセルが多くなる

### 改善案
1. **トピックタクソノミーを固定**（[02 章](02-cross-cutting-issues.md) と連動）。「防災・災害」「外交・安全保障」「経済・財政」「社会保障」… の上位 15–25 カテゴリに必ず紐付ける。
2. ヒートマップは「**カテゴリ × 委員会**」に変える（粒度を揃える）。
3. 委員会も衆議院／参議院でフィルタしたあと、横軸を「Q&A 数 × 平均回避度」のバブルに切り替えるオプション。
4. クリック時の遷移は、修正後の `?topic=`（広域）でも 0 件にならないよう [02 章](02-cross-cutting-issues.md) のフィルタ修正を前提にする。
5. 「不明」「特別委員会（曖昧表記）」は除外。

## 4.3【P0】回避度のスタックバー: 多くの行が赤一色

### 現状
- 上位 20 名のうち、半数以上が `clearCount=0, hedgingCount=0, evasiveCount=N` で**完全に赤**
- これは `totalAnswers < 5` の少サンプルが混じっているため
- 緑（明確）が多い大臣ほど業績がある印象を与え得るが、赤一色が「悪役」として独り歩きするリスク

### 改善案
- **しきい値を導入**: `totalAnswers >= 10` を満たさないと棒グラフに出さない（注釈で除外件数を表示）
- 棒の右側に `n=152` のようにサンプルサイズを併記
- 「答弁役割」フィルタを追加（大臣のみ／副大臣以上／全て）して、委員長や政府参考人を除外しやすく
- 詳細は [05-evasion-score.md](05-evasion-score.md) で

## 4.4【P1】約束トラッカー: status が常に「未確認」固定

### 現状（`CommitmentTracker.jsx`）
```js
const STATUS_LABEL = { unverified: "未確認" };
const STATUS_COLOR = { unverified: "#9ca3af" };
```
- 全件が灰色「未確認」表示
- 「時系列で追跡」と謳っているが、進捗状態の分類が無いので**追跡機能ではない**

### 改善案
- ステータス語彙を 4 つに拡張: `unverified`（未確認）/ `restated`（再答弁あり）/ `progress`（進捗報告あり）/ `realized`（実現）
- 進捗判定は次の通り自動 + 手動:
  - 同じ閣僚が同じトピックで再度発言した Q&A を `restated` 候補とする（自動）
  - フォロー済み Q&A の予算・法案進捗とリンクする場合は手動アノテ
- フィルタチップに「未確認のみ」「再答弁あり」を追加
- 「○月○日に再言及」の小タイムラインをカードに付加

## 4.5【P1】発言者分析: 表が長すぎる／姓名が切れる

### 現状
- 表が **502 行 × 6 列**、ページネーション無し
- 棒グラフの y 軸ラベルが 6 文字で切られ、`三宅外務省大...` のような切り出しになる
- 役職を含めて 6 文字で切るため、`日本放送協会...`（NHK）等が判別困難

### 改善案
1. **テーブル**:
   - 検索ボックス＋並び替え＋ページネーション（25 / 50 / 100 行）
   - 列に「役職タイプ」（議員 / 大臣 / 副大臣 / 政府参考人 / 委員長）バッジを足し、ロール絞り込み
   - 「セッション数」が 1〜2 の発言者を `折りたたむ` チェックボックス
2. **棒グラフ y 軸**:
   - YAxis `width` を 120px に拡張
   - 6 文字制限を 8 文字 + tooltip に
   - 表記の一貫性: `氏名 + 短い役職` で統一（"三宅外務省大..." ではなく "三宅 外務副大臣"）
3. ロード時は「答弁回数 10 件以上」をデフォルト ON（チェックボックスで解除可能）

## 4.6【P2】ダッシュボードと一覧／ホームの境界が曖昧

- ダッシュボードの「最近のセッション」「注目トピック」「カレンダー」はホームに置いた方がストーリーが繋がる
- ダッシュボードは「分析」に振り切り、閲覧導線はホーム / browse に寄せる

### 改善案
- ダッシュボード概要 → ホームに統合（カードを表示）
- ダッシュボードのタブを「トピック分析 / 答弁分析 / コミットメント分析」に絞る
- もしくは「個人分析」「政党分析」「法案分析」のように対象別に分けたタブ構成に再編

---

## 4.7【P2】Recharts の凡例文言が英字キーで漏れる

`MonthlyTrendChart.jsx` で `dataKey="shugiin"` のままなので、Tooltip / Legend で formatter を毎回書く必要がある。これは小さな問題だが、新しいチャートを足すたびに繰り返し発生する。

### 改善案
- データ生成時点で `{ chamber: '衆議院', count: 80 }` のように日本語キーに統一する
- もしくは `<I18nLegend>` のような共通ラッパを作る
