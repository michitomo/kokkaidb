## 7.1 ページ構成（現状）

1. 出所リンク（小さなグレー）
2. H1 委員会名
3. メタ行: 院バッジ、日付、duration、種別バッジ
4. 概要セクション（session_summary + topic chips）
5. 発言タイムライン（SVG 横バー）
6. 発言者一覧（縦リスト）
7. 関連法案チップ
8. 質疑応答（QAPairCard が積み上がる）
9. 発言全文（utterance_segment が `<details>` で折りたたみ）

---

## 7.2【P1】「いま自分が会議のどこを見ているか」が掴めない

### 現状
- 縦に長く（A4 で 6〜10 ページ相当）、目次がない
- 関連法案チップが Q&A セクションの中にひっそりと置かれている
- 動画は外部サイトで開く（埋め込みなし）

### 改善案
1. **左サイドバー（デスクトップのみ）に目次**:
   ```
   ▸ 概要
   ▸ タイムライン
   ▸ 発言者一覧（8名）
   ▸ 関連法案（2件）
   ▸ 質疑応答（53件）
       ・ 防災庁の権限（4件）
       ・ 避難所環境（6件）
       ・ ...（トピック別ジャンプ）
   ▸ 発言全文
   ```
2. ヘッダにスクロール進捗バーを置く（小ニュースサイトでよくある）
3. 「動画を埋め込み（クリックで再生）」のオプション。HLS 直再生は重いので、サムネ + 「該当秒で再生」リンクで OK

---

## 7.3【P1】メタ情報の優先順位

### 現状
- 院バッジ（衆議院）・日付・duration（空文字）・種別バッジ
- duration が空なのでカンマ区切りに違和感

### 改善案
- duration はホームと同じく speakers 集計から算出して表示
- 出席議員数、Q&A 件数、約束事項数を `H1` 直下にバッジで:
  ```
  災害対策特別委員会
  [衆議院] 2026-04-23（木） 3時間6分 / 11名 / 53Q&A / 3約束
  ```

---

## 7.4【P1】タイムラインの視認性・操作性

### 現状（`TimelineView.jsx`）
- 横軸に時間、縦バーで発言者
- 政党カラー（NHK 準拠）が付く
- 棒幅 < 50px で名前が省略されるが、tooltip でフルネーム表示
- Q&A コネクタを表示する trigger はチェックボックス

### 詰まり所
- バー下に発言者名が出るが、衝突して読めない場合がある
- 「自分が読みたいトピックの該当範囲」がタイムライン上で分からない（トピックは別空間）
- 動画リンクは詳細展開時のみ

### 改善案
- バーホバー時に「動画再生 / 該当 Q&A にジャンプ」のミニメニュー
- トピックをタイムライン下に水平ストライプで重ねて表示（時間軸 × トピック）
- 発言者で絞り込んだとき、他の発言者は薄く表示（消すのではなく半透明に）

## 7.5【P1】発言者一覧の表記

### 現状
```
関芳弘 （災害対策特別委員長） — 09:00 / 1分
中川宏昌 （中道改革連合・無所属） — 09:01 / 49分
...
```

### 改善案
- 政党カラーアイコンを左に配置
- 「質問者 / 答弁者」のロールバッジ
- 同じ人が複数セグメントで出る場合（例: 委員長は冒頭・採決・終了で 3 回登場）まとめて表示（`関芳弘 ×3 / 計 5分`）
- 発言者をクリック → 検索ページの「この議員の発言」に絞り込み

---

## 7.6【P0】「全文を表示」と「セグメント全文を表示」の重複

[06 章 6.12](06-filtering-search.md) と重複だが、セッション詳細では特に顕著:
- Q&A の質問・答弁それぞれに「全文を表示」リンク
- ページ下部の「発言全文」セクションでセグメント全文（同じテキスト）が `<details>` で展開可能

→ **同じ全文がページ内に 2 回ある**（メモリ上もバンドル上も）。

### 改善案
- Q&A カード上の「全文」は anchor link `#utt-N` に変え、ページ下部の発言全文へジャンプ
- もしくは Q&A 側を「該当部分を表示」として、Q&A 周辺数発言だけを展開

---

## 7.7【P1】手続きセッション（趣旨説明・採決等）の扱い

### 現状
- `qa_pairs.length === 0` の時、種別バッジを「趣旨説明・採決等」として、発言全文を最初から展開
- これは良い分岐

### 改善案
- バッジに加えて、ページ冒頭にバナーで「このセッションは質疑がありません。冒頭発言・趣旨説明が中心です」
- 採決結果（賛否）が抽出できればここに表示

---

## 7.8【P2】topic chip クリックの挙動

- `data-qa-ids` を持つ button を押すと、その Q&A だけが表示される
- もう一度押すとフィルタ解除
- これ自体はわかりやすいが、トピックが多いセッション（53 Q&A、トピック 10+）でチップが横長になり、改行で見づらい

### 改善案
- トピックチップをスクロール可能な横一列にする or 「もっと見る」展開
- 各チップに該当 Q&A 件数 `(4)` を表示（クリック前に件数感が分かる）

---

## 7.9【P2】「動画を見る」リンクの一貫性

- セッション詳細では「▶ 動画」（外部サイト遷移）
- Q&A カードでは `▶ 動画（2:03〜）`
- 発言全文セグメントでは `▶ 動画`

### 改善案
- 全箇所で「▶ 動画 (2:03〜)」を統一
- ホバーすると「衆議院 TV で開きます」を出す（外部リンク表記）
- 動画の有無で隣にアイコンを添える（音声記録のみ／ライブ中継アーカイブ済み）

---

## 7.10【P2】SEO・SNS シェア

- `<meta property="og:title">` は固定文 + title
- ページごとの description が空（`description` を渡していない）
- OG image が無いので、SNS でリンク貼ると見栄えが悪い

### 改善案
- セッションごとに `description` を `summary.session_summary` の冒頭 120 文字に
- OG image を生成（Astro `@astrojs/og` などでサーバー側生成、もしくはビルド時 PNG 生成）

---

## 7.11【P2】Q&A の「コミットメント」ハイライトが優しすぎる

- 緑のサイドバーで小さく出る
- 「具体的な行動約束」と「努力義務的な約束」を分けたい（[05 章](05-qa-quality-metrics.md) と連動）

---

## 7.12【P2】発言全文セグメント内の段落分割

`(?<=。)` で文末分割しているため、`「○○です。」と述べた` のような引用句中の `。` でも改行される。

### 改善案
- LLM 段階で paragraph 分割をしておく（utterances.json に `paragraphs: [...]` を追加）
- もしくは表示側で `「」` 内の `。` を改行対象から除外する正規表現に変更
