## 6.1【P0】フィルタ結果 0 件時のフォールバックがない

### 現状
> 該当する Q&A ペアが見つかりません。フィルタを変更してください。

[02 章](02-cross-cutting-issues.md) のトピック語彙ズレと相まって、本来データがあるのに「0 件」が頻発する。
ユーザーは「データが無いのか、フィルタが悪いのか」を切り分けられない。

### 改善案
- 0 件時に**条件を 1 つ外したサジェストを表示**:
  - 「トピックを外すと 23 件、委員会を外すと 8 件、発言者を外すと 1 件」
  - クリックで該当条件を 1 つだけ解除
- 「最近検索された語」「人気のフィルタプリセット（防災庁設置法案 / 高額療養費制度 etc）」をサイドバーに

## 6.2【P0】役割フィルタの挙動が直感に反する

### 現状
- 4 つのチェックボックス: `質疑者 / 答弁者 / 政府参考人 / 委員長`
- デフォルト: 全チェック
- 全部外すと「該当なし」。
- 内部的に `selectedRoles.length === ALL_ROLES.length` の時は無視するロジックだが、URL には `role=` が積まれない。

### 問題
- 「役割」に**質問する側／答弁する側**を混ぜて並べてあるが、これは別軸の概念
- 「政府参考人」と「委員長」をオフにしたいだけで、結果に影響が出ない（OR フィルタなので）

### 改善案
- 役割を 2 軸に分割:
  - **発言タイプ**: 質問 / 答弁 / その他（合議運営・採決等）
  - **答弁者属性**: 大臣 / 副大臣 / 政務官 / 政府参考人 / 委員長
- AND/OR 切替を明示
- もしくは「質問者・答弁者だけ表示（委員長・政府参考人を除外）」のシンプルなトグル 1 つに

## 6.3【P1】フィルタの選択肢が多すぎて圧迫感がある

### 現状
- 院・日付・委員会・政党・トピック・関連法案・発言者・役割 = 8 軸
- ファーストビューで全フィルタが一気に視界に入る（[22 のモバイル](screenshots/22-browse-mobile-aboveFold.png) は特に）

### 改善案
- フィルタを**3 階層に再構成**:
  1. トップバー（常時表示）: 院切替・期間（過去 7 日/30 日/全期間）
  2. メインフィルタ（ボタンで開閉）: 委員会・政党・トピック・関連法案
  3. 詳細フィルタ（さらに開閉）: 発言者・役割・回避度範囲・約束あり等
- 適用中のフィルタを**チップで上部に表示**し、× で個別に外せる
- 「保存した検索」機能（localStorage で OK）

---

## 6.4【P1】TSV エクスポートの説明が薄い

### 現状
- ボタン: 「TSV をコピー（6308件）」
- クリップボードにタブ区切りテキストが入る
- フォーマットの説明はどこにも無い

### 改善案
- ボタンの右に小さな ⓘ：押すと「TSV（タブ区切り）でコピーします。Excel でそのまま貼り付けできます」
- ドロップダウンで `TSV / CSV (Excel 用 BOM 付) / JSON / Markdown 表` を選べる
- 「現在のフィルタ条件を URL ごとコピー」も併設（取材で記者が引用を残しやすい）

---

## 6.5【P1】SessionCalendar からの遷移が機能していない

[02 章](02-cross-cutting-issues.md) で既出。`?date=YYYY-MM-DD` を `from` / `to` に展開する修正で、カレンダー → /browse の動線が復活する。

---

## 6.6【P1】ページネーションが 300 件/ページ固定

### 現状
- `PAGE_SIZE = 300` ハードコード
- スマホでは 300 枚の Q&A カードを延々スクロールすることになる

### 改善案
- 件数選択: 25 / 50 / 100 / 300
- もしくは無限スクロール（IntersectionObserver）
- ページ番号 + jump-to-page 入力（記者が "P10 を後で読む" のように URL を保存しやすい）

---

## 6.7【P2】複数選択時の表示が貧弱

`MultiSelect.jsx` の表示:
> 衆議院本会議 他 3 件

- 何が選ばれているかは開かないと見えない
- 削除には開いて再クリック

### 改善案
- 選択済みアイテムをチップで横並び表示し、× で個別削除
- 「全て選択」「全てクリア」のミニボタン

## 6.8【P2】「関連法案」フィルタの ID/タイトル変換が冗長

`FilterPanel.jsx`:
```js
value={selectedLaws.map((id) => {
  const law = lawOptions.find((l) => l.id === id);
  return law ? law.short_title : id;
})}
onChange={(titles) => {
  const ids = titles.map((t) => {...});
}}
```
- ID と title の往復変換が UI でやりにくい
- `MultiSelect` を `{ value, label }` 対応にするのが筋

## 6.9【P0】検索ページの導線・分類

### 現状
- Pagefind UI が単独で出る
- 「[概要] / [Q&A] / [発言]」の 3 種類を分類する説明文が常時表示
- 検索結果にも `[概要]` などのラベルが prefix として現れる

### 改善案
- カテゴリを Pagefind の `filters` で構造化:
  - フィルタタブ: 全て / 概要 / Q&A / 発言
  - URL: `/search?type=qa&q=防災庁`
- 検索結果カードのデザインを統一し、`type` をバッジで表現
- 検索ボックスをグローバルヘッダに常時配置（command-K で開く）

---

## 6.10【P2】検索結果のジャンプ先

Pagefind が結果に付ける anchor は `#qa-001`, `#utt-3` のような ID。詳細ページの該当 Q&A までスクロールはするが、**該当箇所が emphasis されない**（CSS の `:target` も付いていない）。

### 改善案
- `:target { background: rgba(255, 235, 100, 0.4); transition: ... }` で 2 秒ハイライト
- スクロール時に `scroll-margin-top: 80px` でヘッダ分の余白

---

## 6.11【P2】CJK 検索のクエリヒント

- Pagefind は CJK の単語分割が弱い場合がある
- 「2 文字以上で検索してください」「漢字 1 文字検索は無効」のヒントが無い
- 結果 0 件時に検索クエリの正規化候補を出すと親切

---

## 6.12 Q&A カードのインタラクション細部

### 動画リンクの時間表記が小さい
> ▶ 動画（2:03〜）

- アイコンとテキストが薄い色で目立たない
- ホバーすると `title` に `動画を見る（2:03〜）` が出るが、モバイルでは見えない

### 「全文を表示」が二重実装
- `QAPairCard.astro` は `<details>` で開閉
- `FilteredQAList.jsx` は `expandedIds` の Set を React state で管理
- 同じ機能だが挙動が異なり、開いたまま page 遷移しても保持されない

### 改善案
- どちらも `<details>` ベースに統一
- 「全展開 / 全折りたたみ」ボタンを上部に
